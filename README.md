Garment Employee Productivity Analysis Overview

**Productivity Predition of Garment Employees Analysis Dashboard**

Project Overview
This project analyses garment manufacturing production data using Microsoft Power BI to evaluate productivity, workforce efficiency, and production performance across departments and teams.
The dashboard compares actual productivity against targeted productivity and explores how overtime, work-in-progress (WIP), incentives, idle time, workforce size, and style changes relate to production performance.

## Subheading **Objectives**

•	Compare actual productivity with targeted productivity.
•	Identify departments and teams performing above or below their targets.
•	Analyse overtime and idle time across teams.
•	Understand workforce distribution and efficiency.
•	Examine relationships between SMV, WIP, incentives, and productivity.
•	Monitor productivity trends over time.

**Tools and Technologies**

•	Microsoft Power BI — Interactive dashboards and visualizations
•	Power Query — Data cleaning and transformation
•	DAX — Calculated measures and productivity indicators
•	Data modeling — Fact and dimension tables, relationships, and drill-through analysis



**Dataset**

https://archive.ics.uci.edu/dataset/597/productivity+prediction+of+garment+employees

The dataset contains garment production records with fields such as:
•	Date and Quarter
•	Department and Team
•	Targeted Productivity
•	Actual Productivity
•	SMV (Standard Minute Value)
•	WIP (Work in Progress)
•	Overtime
•	Incentive
•	Idle Time and Idle Men
•	Number of Style Changes
•	Number of Workers

**Business Value**

This dashboard supports data-driven decision-making in garment manufacturing by helping users identify productivity gaps, investigate operational inefficiencies, compare team performance, and monitor production trends.



**Conclusion**

The project demonstrates the use of Power BI for transforming production data into meaningful visual insights. It combines data preparation, data modeling, DAX calculations, and interactive reporting to support manufacturing performance analysis.
